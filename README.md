DESIGN DIRECTION

This needs to feel like a genuinely cool modern website, not a generic towing-company WordPress template.

The overall visual direction should be:

premium automotive

dark

sophisticated

high performance

industrial

clean

trustworthy

cinematic

slightly aggressive without feeling tacky

Use a predominantly near-black / charcoal interface with white typography and one strong high-visibility accent colour suitable for vehicle recovery branding.

Think:
premium motorsport website × emergency roadside assistance × modern London automotive company.

Use large typography, excellent whitespace, smooth scroll animations, subtle glassmorphism where appropriate, strong photography/video treatments and tasteful micro-interactions.

Do NOT overload the interface with gradients, flashing lights, cheap warning stripes or cheesy towing graphics.

The website must still be extremely easy to understand for somebody who has just broken down and wants help immediately.

INTERACTIVE HERO

Make the hero the memorable signature element of the website.

Create an interactive animated recovery-truck scene.

Concept:

A premium flatbed recovery truck is positioned within a stylised London road environment.

As the user moves their cursor on desktop, or scrolls/touches on mobile:

the truck subtly reacts with depth/parallax

road markings shift slightly

headlights can softly illuminate

background London silhouettes move at a slower depth layer

the recovery bed or vehicle silhouette can subtly animate

the interaction should feel polished and cinematic rather than like a game

On scroll from the hero into the next section, have the truck visually “travel” a short distance across the page or transition into a vehicle-on-flatbed composition.

Do this using performant CSS, SVG, Canvas, lightweight WebGL or another suitable method.

IMPORTANT:
Animations must never hurt mobile performance, accessibility or Core Web Vitals.

Use prefers-reduced-motion support and replace complex effects with static compositions on low-powered devices.
